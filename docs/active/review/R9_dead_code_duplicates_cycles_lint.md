## Summary for the owner

**What this area does for the player.** Nothing directly: it is the dust in the house. Dead
exports, copied logic, import cycles and lint errors cost the player nothing until they hide a
real bug or slow the next change down. The point of going through them once is so the planning
agent can write a handful of safe delete tickets instead of re-finding each item later.

**How healthy it is: tidier than the tool totals suggest.** Of knip's 201 "unused exports", 127
are a `default` written beside a named export of the same thing (one line each), 13 are used by
the CMS (which the tool is told to ignore), 4 are called by name from the benches, and 49
are code nothing reads. Of the 15 "unused files", every one is a bench scenario or a script
loaded by name. Of the 69 lint errors, 20 are in research folders and scripts eslint should not
lint, 33 are stray imports in tests, 11 are stray imports in the game, and 5 point at logic that
went missing. Of the 68 clones, 17 are filed already, 36 are boilerplate, and 15 are real
duplicated logic in nine groups. The one import cycle is R0's CR4-001; the dependency tool's 24
warnings are all that cycle plus R0's CR4-002.

**The three findings that matter most.**
1. **Forty-nine exports nothing reads, listed for deletion** (CR4-082): each with the
   grep that says so, including the tool's blind spots (CMS and bench use) checked by hand.
2. **Nine groups of logic written twice or three times** (CR4-083): a distance routine written twice in each of two
   forms, a noise hash in three, a random-direction helper in three, a quest-state default in
   two, a `countMatches` twin where one copy already exports it.
3. **Five lint errors that are lost logic, not stray names** (CR4-084): a merge delay constant
   that says 900 while the code uses 1,100, a per-area loot parameter carried through four
   functions and never read, an emoji fallback computed and never drawn, a `variant` prop with no
   effect, and a drag guard duplicated after the real one moved.

**Counts.** 5 findings: 4 `cleanup`, 1 `docs`; 0 `owner-decision`. Verified: see each finding's
`Verified by`.

**Measure first.** Nothing to measure; every item is a grep. After the deletions, re-run the four
