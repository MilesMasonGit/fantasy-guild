# The release package

*D9 of the post-crunch plan ([ideas.md](ideas.md)). Owner interview,
2026-10-09. **Done** (owner closed it 2026-10-09).*

- **First outside playtest after the Atlas and the first skill loops**: once
  the Starter Camp, tutorial, first maps and first loops exist (the game's
  real first hour). Friends or a small group; feedback on the first hours.
- **Release on Steam.** The **store page goes up once the Atlas looks good**
  (after the crunch, when screenshots show the real game), then wishlists
  build through the post-crunch work. Steam's paperwork and fee can be done any
  time before.
- **Saves become real files on disk with backups** (not browser storage inside
  the desktop app) before outside players, and **carry over across updates
  from the first public version** (today other versions are refused until
  1.0). Steam Cloud can come with Steam.
- **Updates through Steam. Crashes report themselves automatically** to a
  service, with the player's consent and a privacy notice.
- **Translation**: T-119 makes text translatable; **which languages, and who
  translates, is decided near release**.
- **Modding: content mods through the CMS, after release.** Players use a
  version of the CMS to make items, Tokens, maps and recipes and share them; no
  code mods. Keep it in mind while building (content stays data, text stays
  translatable).
- **Credits**: every asset credited (T-124), with an in-game Credits screen
  before release.
- **Sound**: added after the crunch, before release (D1).
