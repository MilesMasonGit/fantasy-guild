# The world map as built (brief 380 M2, M3), 2026-11-06

Screens from the running game (dev server, headless Chrome) at 1366 x 768 and 1920 x 1080, a new
game each; the places settled and prices met through the QA panel's helpers (`worldDev.js`).

| File | What it shows |
|---|---|
| `*_01_mat` | The mat before the map opens. |
| `*_02_pan_down_mid` | Mid-pan: the mat and its top bar gliding up, the map coming up from below; hero bar and nav still. |
| `*_03_map_new_game` | A new game: the Hall settled (flag), ring 1 too dear (darkened), rings 2 and 3 out of reach (black and white), fog past ring 3. |
| `*_04_states` | Hall and three places settled, cells ready now (pulsing gold), some too dear (darkened), the rest black and white. |
| `*_05_pulse_frame_a/b` | A ready cell close up, half a second apart: the outline between its two golds. |
| `*_06_hover_out_of_reach_tip` | The pointer on a black-and-white cell: full colour, white outline, the tip (name, land, price, why it is out of reach). |
| `*_07_hover_ready_tip` | The tip of a cell that can be settled now. |
| `*_08_hover_too_dear_tip`, `*_09_panel_too_dear` | A cell too dear: its tip (red counts) and its panel (Settle greyed, what is short under it). |
| `*_10_panel_ready` | The panel of a cell ready now: yields, price, the large Settle. |
| `*_11_panel_settled` | A settled place elsewhere: its mat drawn small, facts, Tokens, yields, Travel. |
| `*_12_rename` | Renaming a settled place on its panel. |
| `*_13_dragged` | The map dragged up and right. |
| `*_14_settle_pan_up_mid` | Settle pressed: the pan back up to the new place. |
| `*_15_arrival_on_mat` | The new place's mat, held by its arrival (darkened, enemies standing), named as the map named it. |
| `*_16_map_to_hall_mid` | The Hall opened from the map: the map set down at once, only the Hall's glide runs. |
| `*_17_wild_ring_shown` | A ring-3 place settled: ring 4 appears, settle-able. |
