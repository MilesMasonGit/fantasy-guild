Terrain look: pixel size and colours

Each picture is the same small patch of mat with real game art on top: an Oak Tree, a Copper Ore Vein, a fighter, an Oak Sapling and two dropped loot items. Only the ground changes between pictures. Pick the one where the ground sits quietly behind the Tokens and still looks like a place.

Rows: how big the ground's pixels are. Columns: today's colours, or the same art made darker and greyer. The Tokens are never changed.

Notes for whoever draws or codes this next
  • Muted filter, applied to the ground layer only: filter: brightness(0.85) saturate(0.7). To bake it into art: multiply every ground colour's brightness by 0.85 and pull its saturation 30 % toward grey.
  • Chunky = the 8 px set: terrain/template/ter_grassb.png, ter_stoneb.png, ter_dirtb.png, ter_waterb.png (64 × 64 sheets) drawn at 4×, so one ground pixel = 4 mat units = 2 Token pixels. There is no chunky sand sheet, so chunky sand is the four cut pieces terrain/ter_sandb0–3 (8 × 8), one per 32-unit square, picked at random.
  • Same-as-Tokens = the 16 px set: terrain/template/ter_grass.png, ter_stone.png, ter_dirt.png, ter_sand.png, ter_water.png drawn at 2×, so one ground pixel = 2 mat units = 1 Token pixel.
  • The edges here are a stand-in. Ground changes on a plain 32-unit staircase. The game would work out a wiggly, natural edge instead (look answer L-3 A); judge the pixel size and colours, not the edge shape.
  • Colours are the raw art files. The game may lay a small per-biome tint over the grass too (terrainRegistry.js); it is not shown here.
  • All scaling is whole-number with hard pixels (image-rendering: pixelated). At game size a same-as-Tokens ground pixel is one screen pixel, the same as a Token pixel.
  • Art used: tokens/nature/tree/token_tree_oak.png, tokens/ore/token_ore_vein_copper.png, heroes/animations/ani_fighter_0.png and ani_ranger_0.png (first standing frame), playmat/props/prop_tree_oak.png (the Oak Sapling's art, 16 px drawn at 4 units a pixel), items/ore/ore_copper.png, items/wood/wood_oak.png, tokens/fish/token_coast.png, items/fish/fish_trout_raw.png, items/fish/fish_shrimp_raw.png.
