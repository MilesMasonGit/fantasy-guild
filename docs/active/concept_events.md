# Events: special Tokens that land on the mat

*Owner interview, 2026-11-12. Replaces the "Events" section of
[concept_living_game.md](concept_living_game.md) for landings and buffs;
visitors (trainers, the merchant, requests) are a later session. Source ideas:
[star_ideas_review.md](star_ideas_review.md) (Weather Lore, Fallen Star).*

## The idea (owner)

Special Tokens occasionally land on the mat and give the chance to gather
special resources, or lots of resources quickly. Two kinds to start:

- **Rich nodes**: a big but limited pool of charges and a high yield per
  cycle; gone once exhausted. *A Copper Ore Comet: 100 charges, 6 copper a
  cycle.* Comets and meteors, a windfall (a fallen giant tree), a fish shoal, a
  wild patch to forage, a treasure cache.
- **Buff Tokens**: give one effect to the Tokens in their reach for a set
  time, then leave. *Rainfall: +20 % Double Loot on Farming in reach for 20
  minutes.* Weather and the like, one per effect name: Speed, Yield, Growth,
  Double Loot, Preservation, Refresh, Lucky, XP.
- **Event-only materials** (star metal, rare seeds) come later, in a small
  pack of their own with recipes that use them.

Trainers (a visitor who gives XP) the owner likes; they come after these.

## The rules (owner, 2026-11-12)

- **How often**: about **once an hour** of play. One event on the mat at a
  time; the next waits until it ends.
- **Picking**: **weighted random** per event (common, uncommon, rare, set in
  the CMS), among the events that fit the place.
- **Where**: each event lists the **regions or terrain** it can land in (a
  shoal only by water, a comet anywhere); it lands on a free spot of the mat.
- **Not tied to tier**: any event can land anywhere it fits. A Mythril Comet
  can land in the first hour; nobody can mine it yet.
- **Ending**: a rich node ends when its **charges** run out; a buff Token when
  its **time** runs out. **A node leaves after about an hour whether or not
  anyone can work it** (owner, 2026-11-13; it used to wait while a hero could work it).
- **Time left shows like a refreshing node's**: the existing timer and charge
  display, no new look.
- **Moving**: by kind. **Buff Tokens move** (drag or right-click them where the
  boost should go); **resource nodes stay** where they land.
- **Reach**: buff Tokens use the **standard reach** (brief 560).
- **Strength**: clearly better than a normal Token, sized per event against
  the balance rules (BALANCE_RULES), never a jackpot that makes normal play
  feel like waiting.
- **One rule everywhere**: an event node is a Token like any other: Speed,
  Double Loot, Lucky, Giant Harvest and its rare table all apply. An event buff
  **adds to** buildings' and Stars' boosts of the same kind, inside the same
  limits, and shows as one more source on the badges (brief 600).
- **Arrival**: a short arrival on the mat (the comet streaks down, the cloud
  drifts in) and a **notification** that jumps to it.
- **Offline**: events land while you're away and heroes work them as normal;
  buffs tick down. The return report names them.
- **Demolish** removes an event Token at once, so the next can come.
- **Stars**: a small events constellation (more often, more charges, longer
  buffs) later, once events are in and played. Not in this brief.

## Not now

- Visitors: trainers, the merchant, requests (living-game doc).
- Instant effects (refill, ripen), optional fights, shrines, event chains.
- An events log in the encyclopedia or collection log.
- Region happenings (a typhoon on the coast) beyond what an event's region list
  gives.
