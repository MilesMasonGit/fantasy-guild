# Skill loops and the board as a puzzle

*D4 of the post-crunch plan ([ideas.md](ideas.md)). Owner interview, started
2026-10-09. **In progress.** Builds on [concept_progression.md](concept_progression.md)
(implicit tiers, chains across skills) and [concept_combat.md](concept_combat.md).*

## Approach

- **One signature mechanic per skill.** Every skill still works Tokens for
  items, but each adds one rule only it has. One twist each keeps the game
  simple and the skills distinct (pillar 3).
- **Layout and adjacency are a main theme across skills.** Many loops reward
  good placement; on the fixed post-Atlas board, arranging the base is the
  main creative act. Players must be able to see it (neighbour effects shown
  while placing, see below).
- **Design the Starter Camp's skills first**: the ones met in the first hour.
  Their loops set the pattern and the Starter Camp and Atlas need them first.
- **Prototype**: sketch every loop's rule here, build the most promising one
  or two quickly in the game (CMS content plus small engine rules), the owner
  plays them, then the rest follow.

- **Node behaviour is another way skills differ.** Spawners will still be used
  often where they fit (Forests spawn trees); they make less sense for ore
  veins, which refill in place. ⚠️ Amends the Atlas decision "spawners only
  for enemies and lures": player-built growing places spawn too.

## Loops

### Forestry

- **Signature: groves.** Trees of **the same species** standing together
  **grow (and regrow) faster**: a dense Oak grove beats a lone Oak, and mixed
  woods get no bonus. Forestry is about the shape of the forest. Example
  effect: "increase growth speed for Oak Saplings" on each Oak.
- **Planting belongs to Farming** (see Farming): a Forest Foundation, like
  Farmland for food, grows a Forest that spawns trees.
- **Planted trees become fixtures like the map's own**: they regrow in place
  after felling and count toward the Token cap.
- **Seeds travel**: Fir seeds earned in a Fir Region can be planted anywhere.
  The map is how the guild first reaches a new tree; planting spreads it.
- **Neighbours**: groves, plus **a variety of buildings with different
  effects**, e.g. a **Lumber Camp** that speeds up Forestry work nearby, and a
  **Sawmill**, a Construction or Crafting station that makes planks.
- **Feeds**: Construction (wood, planks, Foundation tiers), Smithing and fuel
  (charcoal, handles), Fletching (bows, arrows).
- **Rare finds**: a few per tree type (a bird's nest, amber, a map fragment on
  old trees), as loud pops.
