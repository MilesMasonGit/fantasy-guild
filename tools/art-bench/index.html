Notes
  • Everything is drawn at whole-number scales with hard pixels. 1× is game size on a usual screen: one art pixel is one screen pixel, a Token is 64 px.
  • Preview files are read from public/_gen/art-bench/<preset id>/<path under public/assets>; the preset ids are unchanged, gentle, drag, bold unless the script writes presets.json there. Run the brightness script, then press Reload previews.
  • The tint is a plain colour laid over at the chosen strength, the way the game tints ground.
